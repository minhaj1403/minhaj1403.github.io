코딩 환경.

터미널, 파일, Git, GitHub 풀 리퀘스트, 그리고 원하는 코딩 에이전트. SSH로 연결한 내 컴퓨터에서 돌립니다. Mac, 리눅스 서버, 클라우드의 머신 모두요.

엄지 하나로 쓰도록 만들었습니다. 탭은 맨 아래에, 각 탭에서 열어 둔 것은 그 위 띠에, 지금 작업 중인 머신은 맨 위 칩에 있습니다.

기능 보기 시작하기

탭 네 개, 엄지 하나

모든 것이 엄지가 이미 놓여 있는 아래쪽 바 뒤에 있습니다.

터미널

  • 머신마다 터미널을 여러 개 열고, 탭 위 띠에서 바꿔 가며 씁니다.
  • 키보드 위에 ESC, CTRL, ALT와 방향키를 모아 둔 추가 키 바가 있습니다.
  • 키보드는 터미널을 눌렀을 때만 올라오므로, 탭을 옮겨도 튀어나오지 않습니다.
  • 자리를 비워도 터미널은 머신에서 계속 돌아가고, 돌아오면 그대로 이어집니다.

파일

  • 작업 폴더를 트리로 보여 주고, 파일과 폴더마다 Git 상태를 표시합니다. 변경됨, 추가됨, 추적되지 않음.
  • 텍스트는 문법 강조, 줄 번호, 줄 바꿈, 실행 취소와 다시 실행을 갖춘 편집기에서 열립니다.
  • 마크다운 미리 보기, 그리고 이미지, 동영상, 오디오, PDF 뷰어가 있습니다.
  • 새로 만들기, 이름 바꾸기, 복사, 잘라내기, 붙여넣기를 실행 취소와 함께. SSH 호스트에서는 올리고 내려받습니다.

코딩 에이전트

  • 원하는 코딩 에이전트와 대화합니다. Claude Code나 Codex가 작업 공간이 있는 머신에서 돌아갑니다.
  • 모델과 추론 강도, 권한 모드를 고릅니다. 수정할 때마다 묻게 할 수도, 확인을 아예 건너뛰게 할 수도 있습니다.
  • 대화 안에서 글자를 찾고, 지난 대화를 검색합니다.
  • 에이전트가 언급한 파일을 누르면 열리고, 뒤로 가면 다시 대화로 돌아옵니다.
  • 다른 곳에 있는 동안 에이전트가 답하거나 권한을 물으면 알림이 옵니다.

Git과 풀 리퀘스트

  • 저장소의 변경 사항을 파일별 diff와 함께 봅니다. 스테이지, 해제, 되돌리기, 커밋, 푸시, 풀.
  • 브랜치를 옮기고 새로 만듭니다.
  • 작업 중인 저장소의 GitHub 풀 리퀘스트를 필터와 함께 봅니다. 읽고, 리뷰하고, 머지하고, 새로 엽니다.
  • Git은 휴대폰이 아니라 작업 공간이 있는 머신에서 돌아갑니다.

탭을 차례로 보여 주는 중입니다. 하나를 누르면 멈춥니다.

안드로이드와 iOS

어느 휴대폰에서든 같은 탭, 같은 머신.

Android

안드로이드 휴대폰과 태블릿을 위해 만들었습니다. 내 머신과 에이전트를 SSH로 iOS에서처럼 그대로 씁니다.

안드로이드 7 이상. 휴대폰, 태블릿, 삼성 DeX.

iOS

iPhone과 iPad를 위해 만들었습니다. 내 머신과 에이전트를 SSH로 안드로이드에서처럼 그대로 씁니다.

iOS 18 이상.

주머니 속에서 쓰는 내 머신들

Mac이나 서버를 키나 비밀번호로 추가하면 작업 공간으로 열립니다. 여러 SSH 호스트가 동시에 연결된 채로 있고, 맨 위 칩에서 서로 오갑니다.

  • 호스트마다 SSH 연결을 하나만 공유하므로, 파일과 Git, 에이전트가 두 번 로그인하라고 하지 않습니다.
  • 연결이 끊겨도 터미널과 에이전트 대화는 호스트에서 계속 돌아가고, 내 다른 기기에서도 열 수 있습니다.
  • 저장한 비밀번호와 앱에서 만든 SSH 키는 지문 뒤에 보관됩니다.
  • 명령 팔레트, 그리고 모든 탭에서 열려 있는 것을 한눈에 보는 전환 화면이 있습니다.

원하는 에이전트를, 쓰던 머신 그대로

Claude Code나 Codex가 작업 공간이 있는 머신에서 돌아가고, 손에 든 휴대폰으로 거기에 닿습니다. 새 대화를 열면 어떤 에이전트를 쓸지 묻고, 없으면 설치해 줍니다.

  • 대화마다 에이전트와 모델, 추론 강도, 권한 모드를 따로 둡니다.
  • 모든 대화가 최신순 한 목록에 모이고, 에이전트가 표시됩니다.
  • 에이전트가 일을 마치거나 물어볼 게 생기면, 어디에 있든 바로 알림이 옵니다.
  • 아직 보지 않은 소식은 탭에 숫자로 쌓입니다. 누르면 그 대화가 열립니다.

휴대폰만이 아닙니다

태블릿과 삼성 DeX, iPad에서는 Dex가 데스크톱 IDE처럼 펼쳐집니다. 옆 패널에 파일이나 Git, 에이전트 대화가, 그 옆에 작업 화면이 놓입니다.

시작하기

  1. 설치

    Dex는 안드로이드 7 이상, 그리고 iOS 18 이상의 iPhone과 iPad에서 돌아갑니다.

  2. 앱 열기

    짧은 둘러보기가 탭들을 보여 주고, 머신을 추가하는 방법을 알려 줍니다.

  3. 내 머신 추가

    주소와 사용자, 그리고 키나 비밀번호로 호스트를 추가합니다. 호스트를 누르고 호스트 키 지문을 한 번 신뢰하면, 파일과 Git, 에이전트가 그 머신으로 따라갑니다.
