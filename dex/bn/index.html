আপনার ফোনের জন্য
কোডিং পরিবেশ।

টার্মিনাল, ফাইল, Git, GitHub পুল রিকোয়েস্ট আর আপনার পছন্দের কোডিং এজেন্ট, ফোনেই চলে অথবা SSH দিয়ে নিজের কম্পিউটারে।

এক আঙুলে চালানোর মতো করে সাজানো। নিচে ট্যাব, তার উপরের সারিতে প্রতিটি ট্যাবে যা খোলা আছে, আর উপরে চিপে এখন যে মেশিনে আছেন সেটি।

কী করে দেখুন নিজে বিল্ড করুন

চারটি ট্যাব, এক আঙুল

সবকিছু নিচের বারের পেছনে, যেখানে আপনার আঙুল এমনিতেই থাকে।

টার্মিনাল

  • প্রতি মেশিনে একাধিক টার্মিনাল, ট্যাবের উপরের সারি থেকে বদলানো যায়।
  • কিবোর্ডের উপরে বাড়তি কি এর সারি, ESC, CTRL, ALT আর তীর চিহ্ন সহ।
  • টার্মিনালে চাপ দিলে তবেই কিবোর্ড ওঠে, তাই ট্যাব বদলালে সেটি লাফিয়ে ওঠে না।
  • ফোনের ভেতরেই একটি লিনাক্স সিস্টেম: এক কমান্ডেই Python, Git, Node.js আর আরও অনেক কিছু ইনস্টল করুন।

ফাইল

  • ওয়ার্কস্পেস ফোল্ডারের ট্রি, প্রতিটি ফাইল ও ফোল্ডারে Git অবস্থা সহ: পরিবর্তিত, যোগ করা, ট্র্যাক না করা।
  • টেক্সট খোলে এমন একটি এডিটরে, যাতে সিনট্যাক্স হাইলাইট, লাইন নম্বর, র‍্যাপিং, আনডু আর রিডু আছে।
  • মার্কডাউন প্রিভিউ, আর ছবি, ভিডিও, অডিও ও PDF দেখার ভিউয়ার।
  • নতুন, নাম বদল, কপি, কাট আর পেস্ট, আনডু সহ। SSH হোস্টে আপলোড আর ডাউনলোড।

কোডিং এজেন্ট

  • আপনার পছন্দের কোডিং এজেন্টের সঙ্গে আলাপ, Claude Code বা Codex, ওয়ার্কস্পেস যে মেশিনে সেখানেই চলে।
  • মডেল, এফোর্ট আর অনুমতির ধরন বেছে নিন, প্রতিবার সম্পাদনার আগে জিজ্ঞেস করা থেকে শুরু করে একেবারেই না জিজ্ঞেস করা পর্যন্ত।
  • কথোপকথনের ভেতরে লেখা খুঁজুন, আর আগের আলাপগুলোতে সার্চ করুন।
  • এজেন্ট যে ফাইলের কথা বলে তাতে চাপ দিলে সেটি খোলে, ফিরে গেলে আবার আলাপেই।
  • আপনি অন্য কোথাও থাকলে এজেন্ট উত্তর দিলে বা অনুমতি চাইলে নোটিফিকেশন আসে।

Git ও পুল রিকোয়েস্ট

  • রিপোজিটরির পরিবর্তন, প্রতিটি ফাইলের ডিফ সহ। স্টেজ, আনস্টেজ, বাতিল, কমিট, পুশ, পুল।
  • ব্রাঞ্চ বদলান আর নতুন ব্রাঞ্চ বানান।
  • ওয়ার্কস্পেসের রিপোর GitHub পুল রিকোয়েস্ট, ফিল্টার সহ। পড়ুন, রিভিউ করুন, মার্জ করুন, বা নতুন একটি খুলুন।
  • Git চলে ওয়ার্কস্পেস যে মেশিনে সেখানে, ফোনে নয়।

ট্যাবগুলো ঘুরে ঘুরে দেখাচ্ছে। একটিতে চাপ দিলে থেমে যাবে।

অ্যান্ড্রয়েড আর iOS

যে ফোনই হোক, একই ট্যাব আর একই মেশিন।

Android

আপনার ফোনে একটি পূর্ণ লিনাক্স সিস্টেম। এক কমান্ডেই Python, Git আর Node.js এর মতো টুল ইনস্টল করুন।

অ্যান্ড্রয়েড ৭ বা তার পরের সংস্করণ। ফোন, ট্যাবলেট আর Samsung DeX।

iOS

iPhone আর iPad এর জন্য বানানো। আপনার মেশিন আর এজেন্ট SSH দিয়ে অ্যান্ড্রয়েডের মতোই কাজ করে।

iOS ১৮ বা তার পরের সংস্করণ।

পকেট থেকেই আপনার মেশিনগুলো

আপনার ~/.ssh/config এর হোস্টগুলো ওয়ার্কস্পেস হিসেবে খোলে। ফোন আর যত খুশি SSH হোস্ট একসঙ্গে যুক্ত থাকে, আর উপরের চিপ থেকে এদের মধ্যে বদল করা যায়।

  • প্রতি হোস্টে একটিই শেয়ার করা SSH সংযোগ, তাই ফাইল, Git আর এজেন্ট দুবার লগইন চায় না।
  • সংযোগ কেটে গেলেও টার্মিনাল আর এজেন্টের আলাপ হোস্টে চলতে থাকে, আর আপনার অন্য ডিভাইসেও খোলা যায়।
  • সেভ করা পাসওয়ার্ড আর অ্যাপে বানানো SSH কি, আপনার আঙুলের ছাপের আড়ালে।
  • একটি কমান্ড প্যালেট, আর সব ট্যাবে যা খোলা আছে তার একটি সুইচার।

আপনার পছন্দের এজেন্ট, আপনার মেশিনেই

Claude Code বা Codex চলে ওয়ার্কস্পেস যে মেশিনে সেখানে, আর হাতের ফোন থেকেই তাতে পৌঁছানো যায়। নতুন আলাপ শুরু করলে কোন এজেন্ট চান জিজ্ঞেস করে, না থাকলে ইনস্টল করে দিতে চায়।

  • প্রতিটি আলাপ নিজের এজেন্ট, মডেল, এফোর্ট আর অনুমতির ধরন ধরে রাখে।
  • সব আলাপ এক তালিকায়, নতুনগুলো আগে, কোন এজেন্ট তা চিহ্নিত।
  • এজেন্ট কাজ শেষ করলে বা আপনাকে দরকার হলে সঙ্গে সঙ্গে নোটিফিকেশন, আপনি যেখানেই থাকুন।
  • না দেখা আপডেট ট্যাবে গোনা থাকে। একটিতে চাপ দিলে সেই আলাপ খোলে।

কেবল ফোনেই নয়

ট্যাবলেট, Samsung DeX আর iPad এ Dex ডেস্কটপ IDE এর মতো ছড়িয়ে যায়: পাশের প্যানেলে ফাইল, Git বা এজেন্টের আলাপ, আর তার পাশে আপনার কাজ।

শুরু করা

  1. ইনস্টল করুন

    Dex চলে অ্যান্ড্রয়েড ৭ বা তার পরের সংস্করণে, আর iOS ১৮ বা তার পরের সংস্করণের iPhone ও iPad এ।

  2. অ্যাপটি খুলুন

    অ্যান্ড্রয়েডে প্রথমবার চালু হলে ডিভাইসে একটি ছোট লিনাক্স সিস্টেম তৈরি হয়। দুটোতেই একটি ছোট পরিচিতি দেখায়।

  3. আপনার মেশিন যোগ করুন

    ওয়ার্কস্পেস চিপ থেকে SSH হোস্ট যোগ করুন ব্যবহার করুন, অথবা ~/.ssh/config এ একটি হোস্ট লিখুন। হোস্টে চাপ দিন, একবার লগইন করুন, তারপর ফাইল, Git আর এজেন্ট আপনার সঙ্গে সেখানে যায়।

সোর্স থেকে বিল্ড

Dex বিল্ড হয় অ্যান্ড্রয়েড স্টুডিওর ভেতরে আসা JDK দিয়ে।

export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"
./gradlew :app:assembleDebug

APK জমা হয় app/build/outputs/apk/debug/ এ। iOS অ্যাপটি নিজের প্রজেক্ট থেকে Xcode এ বিল্ড হয়।

Dex একটি ব্যক্তিগত প্রকল্প আর এর রিপোজিটরিগুলো আপাতত ব্যক্তিগত, তাই এখনো কোনো পাবলিক ডাউনলোড নেই।
